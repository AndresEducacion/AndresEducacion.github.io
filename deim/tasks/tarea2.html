DEIM / Tarea 2

Explica una mecánica de videojuego

Piensa en tu videojuego favorito y explica uno de sus procesos con el lenguaje de las funciones.

Qué tienes que hacer

  1. Define la lista de instrucciones que componen el proceso que has escogido. Esa será tu receta.
  2. Define qué variables intervienen. Esos serán tus ingredientes.
  3. Plantea una idea de código en la que declares las funciones que necesitan las acciones de tu proceso. Es como crear tus propios utensilios para cocinar los ingredientes a tu gusto y conseguir el objetivo de la receta.

No hace falta que funcione: es pseudocódigo. Lo importante es que la lógica sea clara y que uses bien variables, condicionales y funciones. Repasa la lección de funciones.

Caso escogido

El sistema de portales

1 · Desglose del proceso

  1. Se abre un portal azul.
  2. Se abre un portal naranja.
  3. Los portales solo se pueden poner en superficies blancas.
  4. Todo lo que entra por el portal azul sale por el naranja, y al revés.
  5. Todo lo que entra conserva su inercia (su velocidad).

2 · Variables

portalAzul, portalNaranja, objeto, velocidadObjeto, superficieBlanca.

3 · Planteamiento de código

// Función que se encarga de abrir portales
void AbrirPortal(bool superficieBlanca)
{
    if (superficieBlanca)                 // solo en superficies blancas
    {
        // haz un portal en esa pared del color actual
        if (portalAzulAbierto)
        {
            // cambia al portal naranja
        }
        else
        {
            // cambia al portal azul
        }
    }
}

// Función que se encarga del funcionamiento de los portales
void Portal(Vector3 posicionObjeto, Vector3 velocidadObjeto)
{
    if (/* el objeto cruza el portal azul */)
    {
        // desaparece ese objeto y aparece uno idéntico en la posición del portal naranja
        // su velocidad de salida es igual a velocidadObjeto, para que mantenga la inercia
    }
    else if (/* el objeto cruza el portal naranja */)
    {
        // desaparece ese objeto y aparece uno idéntico en la posición del portal azul
        // su velocidad de salida es igual a velocidadObjeto, para que mantenga la inercia
    }
}

Fíjate: para comprobar un booleano basta con if (superficieBlanca). Si escribes if (superficieBlanca = true), con un solo =, estás asignando, no comparando.
