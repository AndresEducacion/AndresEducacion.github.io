DEIM / Lección 03 · Unity

Fundamentos de Unity

Primeros conceptos para entender cómo funciona Unity y empezar a programar en C#.

01 · ¿Qué es Unity?

Unity es una plataforma de desarrollo en tiempo real y un motor gráfico para crear videojuegos, aplicaciones interactivas 2D y 3D, realidad virtual y aumentada, simulaciones y más.

Es multiplataforma: un mismo proyecto puede publicarse en PC, consolas, móviles y web.

Aunque está muy enfocado a los videojuegos, es útil en muchos otros campos: arte audiovisual reactivo, instalaciones, herramientas creativas para lo visual y lo sonoro, mediación cultural en museos o accesibilidad.

Unity se programa en C#, un lenguaje moderno orientado a objetos inspirado en C, C++ y Java. Es lo que vimos en la lección anterior.

02 · Interfaz

  1. Hierarchy: lista todos los objetos de la escena actual.
  2. Scene: la vista donde se colocan y modifican los objetos.
  3. Game: muestra cómo se verá el juego al ejecutarlo.
  4. Inspector: permite ver y modificar las propiedades y componentes del objeto seleccionado.
  5. Project: los archivos del proyecto (scripts, modelos, sonidos…).

03 · Tipos de objetos

En Unity, todo lo que aparece en una escena es un GameObject. Según su función, pueden ser:

GameObject vacío

Sin forma ni comportamiento. Sirve de contenedor u organizador: las «carpetas» de la escena también son objetos.

Cámara

Muestra una parte del espacio. Lo que ve quien juega es lo que ve una cámara.

Luz

Ilumina la escena. Hay varios tipos: direccional (el sol), puntual, foco…

Sprites (2D)

Imágenes usadas en juegos 2D.

Modelos 3D

Objetos con volumen: personajes, escenarios…

UI

Botones, textos, barras de vida y menús. Viven dentro de un Canvas.

04 · Tipos de componentes

Los componentes se añaden a un GameObject para darle forma, comportamiento o funciones. Todos se pueden controlar desde código.

ComponentePara qué sirve
TransformPosición, rotación y escala. Todos los objetos lo tienen.
RendererMuestra el objeto en pantalla.
ColliderDetecta colisiones entre objetos.
RigidbodyAplica físicas: gravedad y fuerzas.
Script (C#)Programa el comportamiento del objeto.
AudioSourceReproduce sonidos.
AnimatorControla las animaciones.

05 · Variables y funciones específicas

Tipo o funciónPara qué sirve
Vector2 · Vector3Posiciones o movimientos en 2D y en 3D.
GameObjectReferencia a un objeto del juego.
TransformPosición, rotación y escala.
QuaternionRotaciones.
ColorColores.
Time.deltaTimeSegundos que han pasado desde el fotograma anterior. Multiplicar por él hace que el movimiento vaya igual de rápido con muchos o pocos fotogramas por segundo.
Input.GetAxis()Movimiento continuo con teclado o mando.
Input.GetKey() · GetKeyDown()Detecta teclas: mantenida o pulsada una vez.
 
// Vector2 y Vector3: posiciones o movimientos en 2D y 3D
Vector2 movimiento2D = new Vector2(1f, 0f);
transform.Translate(movimiento2D * Time.deltaTime);

Vector3 movimiento3D = new Vector3(0f, 0f, 1f);
transform.position += movimiento3D * Time.deltaTime;

// GameObject: referencia a un objeto del juego
GameObject enemigo = GameObject.Find("Enemy");

// Transform: posición, rotación y escala
transform.position = new Vector3(0f, 2f, 0f);
transform.localScale = new Vector3(2f, 2f, 2f);

// Quaternion: rotaciones
transform.rotation = Quaternion.Euler(0f, 90f, 0f);

// Color
Renderer r = GetComponent<Renderer>();
r.material.color = Color.red;

// Time: 5 unidades por segundo, vaya el juego a los fotogramas que vaya
float velocidad = 5f;
transform.Translate(Vector3.forward * velocidad * Time.deltaTime);

// Input.GetAxis(): movimiento continuo (teclado o mando)
float horizontal = Input.GetAxis("Horizontal");
float vertical = Input.GetAxis("Vertical");
transform.Translate(new Vector3(horizontal, 0f, vertical) * 5f * Time.deltaTime);

// Input.GetKey() / GetKeyDown(): detección de teclas
if (Input.GetKey(KeyCode.Space)) Debug.Log("La tecla espacio está pulsada");
if (Input.GetKeyDown(KeyCode.Space)) Debug.Log("Se ha pulsado espacio una vez");

Nota: estos fragmentos van dentro de un método como Start() o Update() de un script; en la sección 07 tienes uno completo.

06 · Variables públicas

Una variable pública se puede modificar desde el Inspector sin cambiar el código.

  1. Se declara con la palabra public.
  2. Aparece automáticamente en el Inspector.
  3. Desde el Inspector puedes cambiar números, activar o desactivar booleanos y arrastrar objetos a las variables para que el código los use.
using UnityEngine;

public class Player : MonoBehaviour
{
    public int vidas = 3;               // número entero
    public float velocidad = 5f;        // decimal
    public bool estaVivo = true;        // interruptor
    public GameObject enemigo;          // se arrastra desde la Hierarchy
    public Vector3 posicionInicial;     // se escribe en el Inspector

    void Start()
    {
        Debug.Log("Vidas iniciales: " + vidas);
        transform.position = posicionInicial;

        if (enemigo != null)
        {
            Debug.Log("Enemigo asignado: " + enemigo.name);
        }
    }

    void Update()
    {
        // El movimiento va en Update: se ejecuta en cada fotograma
        transform.Translate(Vector3.forward * velocidad * Time.deltaTime);
    }
}

07 · Primer script en Unity

Todo lo visto en C# dentro de un script de Unity. Start() se ejecuta una vez al empezar; Update(), una vez por fotograma.

using UnityEngine;

public class EjemploMono : MonoBehaviour
{
    // Tipos de variables
    int numeroEntero = 10;
    float numeroDecimal = 3.5f;
    bool activo = true;
    string nombre = "Unity";
    char letra = 'U';
    int[] listaNumeros = { 2, 4, 6, 8 };
    string[] listaSaludos = { "heyy", "hola", "klk" };

    void Start()
    {
        Debug.Log("Start ejecutado");

        // Operadores
        int resultado = numeroEntero * 2;
        float division = numeroDecimal / 2f;   // para obtener decimales, divide entre un float (con f)
        Debug.Log("Resultado multiplicación: " + resultado);
        Debug.Log("Resultado división: " + division);

        // If con operador lógico. Un bool solo en la condición equivale a comprobar que es true
        if (activo && numeroEntero > 5)
        {
            Debug.Log("Condición del if cumplida");
        }

        // Bucle for que recorre un array
        for (int i = 0; i < listaNumeros.Length; i++)
        {
            Debug.Log("Número en lista: " + listaNumeros[i]);
        }

        // Llamada a una función: da igual si se declara antes o después
        MostrarMensaje("¡Hola desde la función!");
    }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            Debug.Log("Has pulsado la barra espaciadora");
        }
    }

    // Función propia
    void MostrarMensaje(string texto)
    {
        Debug.Log("Mensaje: " + texto);
    }
}

Ojo: en C# las variables siempre van dentro de una clase. Si las escribes fuera de public class … { }, Unity da error de compilación.

08 · Cuándo se ejecuta cada función

Unity llama por su cuenta a ciertas funciones de tus scripts en momentos concretos. Lo importante es saber cuál usar para cada cosa.

FunciónCuándo se ejecutaPara qué
Start()Una vez, antes del primer fotograma.Preparar valores y buscar referencias.
Update()Una vez por fotograma (más o menos veces según el ordenador).Leer el teclado y el ratón, mover cosas sin físicas.
FixedUpdate()A intervalos fijos: 50 veces por segundo por defecto.Todo lo que toque un Rigidbody: fuerzas y velocidades.
OnCollisionEnter()Al chocar con otro collider.Golpes, daño, rebotes.
OnTriggerEnter()Al entrar en un collider marcado como trigger.Recoger objetos, zonas, metas.
 
using UnityEngine;

public class Saltador : MonoBehaviour
{
    public float fuerzaSalto = 6f;
    Rigidbody rb;
    bool quiereSaltar;

    void Start()
    {
        rb = GetComponent<Rigidbody>();      // una vez: guardamos la referencia
    }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))  // el teclado se lee en Update
        {
            quiereSaltar = true;
        }
    }

    void FixedUpdate()
    {
        if (quiereSaltar)                     // las físicas se aplican en FixedUpdate
        {
            rb.AddForce(Vector3.up * fuerzaSalto, ForceMode.Impulse);
            quiereSaltar = false;
        }
    }
}

Por qué así: si lees la tecla en FixedUpdate puedes perder pulsaciones, y si aplicas la fuerza en Update el salto cambia según los fotogramas por segundo de cada ordenador.

09 · Hablar con otros componentes

Desde un script puedes controlar cualquier otro componente del mismo GameObject con GetComponent<Tipo>(). Guárdalo en una variable en Start() para no buscarlo en cada fotograma.

using UnityEngine;

public class Bombilla : MonoBehaviour
{
    Renderer rend;
    AudioSource sonido;

    void Start()
    {
        rend = GetComponent<Renderer>();
        sonido = GetComponent<AudioSource>();
    }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.E))
        {
            rend.material.color = Random.ColorHSV();   // cambia de color
            sonido.Play();                             // y suena
        }
    }
}

10 · Colisiones y triggers

Collider

Da forma física al objeto para detectar contactos: caja, esfera, cápsula… No hace que se mueva.

Rigidbody

Hace que el objeto obedezca a las físicas: gravedad, fuerzas, choques. Al menos uno de los dos objetos que chocan debe tenerlo.

Is Trigger

Si marcas un collider como trigger, deja de ser sólido: los objetos lo atraviesan y Unity te avisa al entrar.

Detectar un choque

using UnityEngine;

public class Jugador : MonoBehaviour
{
    public int vidas = 3;

    void OnCollisionEnter(Collision choque)
    {
        if (choque.gameObject.CompareTag("Enemigo"))   // ¿contra qué he chocado?
        {
            vidas--;
            Debug.Log("¡Au! Vidas: " + vidas);
        }
    }
}
¡Au! Vidas: 2

Recoger un objeto con un trigger

using UnityEngine;

public class Moneda : MonoBehaviour
{
    public int valor = 10;

    void OnTriggerEnter(Collider otro)
    {
        if (otro.CompareTag("Player"))       // solo la recoge el jugador
        {
            Debug.Log("+" + valor + " puntos");
            Destroy(gameObject);             // la moneda desaparece
        }
    }
}

En 2D todo lleva el sufijo 2D: Rigidbody2D, BoxCollider2D, OnCollisionEnter2D(Collision2D c) y OnTriggerEnter2D(Collider2D c). Las etiquetas (tags) se asignan en el Inspector, arriba del todo.

11 · Prefabs e Instantiate

Un prefab es un GameObject guardado como plantilla para crear copias durante el juego: balas, enemigos, monedas…

  1. Monta el objeto en la escena con todos sus componentes.
  2. Arrástralo de la Hierarchy a la ventana Project: se vuelve azul, ya es un prefab.
  3. Arrastra el prefab a una variable pública del script que lo va a crear.
using UnityEngine;

public class Disparador : MonoBehaviour
{
    public GameObject balaPrefab;     // se arrastra desde Project
    public float velocidad = 12f;

    void Update()
    {
        if (Input.GetMouseButtonDown(0))   // clic izquierdo
        {
            GameObject bala = Instantiate(balaPrefab, transform.position, transform.rotation);
            bala.GetComponent<Rigidbody>().velocity = transform.forward * velocidad;
            Destroy(bala, 3f);             // la borra a los 3 segundos
        }
    }
}

Versión de Unity: en Unity 6 la velocidad del Rigidbody se llama linearVelocity. velocity sigue funcionando (con un aviso) y es la que existe en versiones anteriores, por eso la usamos en los ejemplos.

Tienes más scripts listos para usar (salto, cámara que sigue, recolectables, generador de enemigos…) en el repositorio de códigos, y la guía del proyecto en la Tarea 3.

13 · Comprueba lo que sabes

Intenta responder con tus palabras antes de desplegar cada respuesta.

¿Qué es Unity y qué lenguaje usa?

Un motor de desarrollo en tiempo real para crear videojuegos y aplicaciones interactivas 2D, 3D, VR y AR en varias plataformas. Se programa en C#.

Nombra dos tipos de objetos y un uso de cada uno.

Por ejemplo: una cámara, que muestra lo que ve quien juega, y un GameObject vacío, para agrupar los objetos de un nivel.

¿Qué diferencia hay entre un Collider y un Rigidbody?

El Collider da forma física para detectar contactos; el Rigidbody hace que el objeto obedezca a las físicas (gravedad y fuerzas). Para que haya colisión, al menos uno de los dos objetos necesita Rigidbody.

¿Qué es Time.deltaTime y por qué se multiplica por él?

Los segundos que han pasado desde el fotograma anterior. Multiplicando por él, el movimiento va a la misma velocidad con muchos o pocos fotogramas por segundo.

¿Qué devuelve Input.GetAxis("Horizontal")?

Un número entre −1 y 1 según se pulse izquierda (A, ←), nada o derecha (D, →), con una pequeña suavización.

¿Qué es un Vector3?

Un grupo de tres números (x, y, z) que representa una posición, una dirección o una velocidad en 3D.

¿Qué función usarías para detectar que el jugador recoge una moneda?

OnTriggerEnter (u OnTriggerEnter2D en 2D), con el collider de la moneda marcado como trigger y comprobando la etiqueta con CompareTag("Player").
