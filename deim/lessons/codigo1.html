Fundamentos de programación en p5.js

Los conceptos básicos de cualquier lenguaje, con respuesta visual inmediata. Todos los ejemplos se ejecutan aquí mismo: cambia un número, pulsa Ctrl+Enter y mira qué pasa.

01 · ¿Qué es la programación?

Programar es crear un conjunto de instrucciones que le dicen a un ordenador cómo realizar una tarea.

Esas instrucciones se escriben en un lenguaje que el ordenador puede entender. Unos traductores, los intérpretes o compiladores, leen el texto y ejecutan las acciones que marca. Aprender a programar es como aprender inglés, música o braille: damos sentido a unos signos para crear un sistema que funciona.

  • El código se ejecuta de arriba abajo, línea a línea. El orden importa.
  • Cada lenguaje tiene sus reglas de escritura (sintaxis): en JavaScript cada instrucción acaba en ; y los bloques van entre llaves { }.
  • Los comentarios empiezan por //: el ordenador los ignora y sirven para explicar el código.

La estructura de un sketch

setup()

Se ejecuta una sola vez al empezar. Aquí se crea el lienzo y se preparan los valores iniciales.

draw()

Se repite unas 60 veces por segundo, en bucle. Cada repetición es un fotograma: aquí va lo que se mueve o cambia.

Las coordenadas

El lienzo es una cuadrícula de píxeles. El punto (0, 0) está arriba a la izquierda: x crece hacia la derecha e y crece hacia abajo. Pasa el ratón por el lienzo para ver sus coordenadas.

02 · Variables

Una variable es un contenedor que guarda información que puede cambiar mientras el programa se ejecuta.

Piensa en tus variables como la paleta de elementos con la que después vas a jugar, como las piezas de un juego de construcción o los objetos de un inventario.

  1. Se declara con let y un nombre: let x.
  2. Con = se le asigna un valor: let x = 300;
  3. Para usarla, se escribe su nombre donde iría el valor: circle(x, 200, size);

03 · Operadores

Los operadores hacen operaciones con números y con texto, y comparan valores.

TipoOperadores
Aritméticos+ - * / · % resto de la división · ** potencia
Asignación abreviadax += 2 es x = x + 2 · x++ es x = x + 1
Comparación=== igual · !== distinto · > < >= <=

Ojo: = asigna un valor y === compara. if (x = 5) no pregunta si x vale 5: le da el valor 5.

04 · Condicionales

Los condicionales toman decisiones: si se cumple una condición, se ejecuta un bloque de código.

  • if: comprueba una condición y, si se cumple, ejecuta lo que hay entre llaves.
  • else if: si la anterior no se cumple, prueba otra condición.
  • else: si no se cumple ninguna, se ejecuta esto.

05 · Operadores lógicos

Sirven para combinar varias condiciones dentro del mismo paréntesis.

OperadorSignificadoSe cumple si…
&&yse cumplen las dos: x > 100 && x < 200
||ose cumple al menos una: x > 200 || y < 50
!nola condición no se cumple: !mouseIsPressed

06 · Bucles

Un bucle repite un fragmento de código mientras se cumple una condición, sin tener que escribirlo muchas veces.

Recuerda: draw() ya es un bucle que p5.js repite en cada fotograma. Unity y cualquier motor en tiempo real funcionan igual.

for: cuando sabes cuántas vueltas

Entre paréntesis lleva tres partes: desde dónde empieza el contador, hasta cuándo sigue y cuánto avanza en cada vuelta.

while: mientras se cumpla una condición

Bucles anidados: una cuadrícula

Un bucle dentro de otro recorre filas y columnas. Con dist() cada punto reacciona a la distancia del ratón.

07 · Funciones

Una función agrupa instrucciones con un nombre para poder invocarlas en cualquier momento.

Si las variables son los ingredientes, las funciones son las recetas. Entre paréntesis reciben los datos que necesitan (parámetros) y, con return, pueden devolver un resultado a quien las llamó.

Buenas prácticas: una función debe hacer una sola cosa, y su nombre debe decir cuál. Igual que con las variables, no puede haber dos funciones con el mismo nombre.

08 · Interacción: eventos y arrays

Algunas funciones las llama p5.js por ti cuando pasa algo: mousePressed() en cada clic y keyPressed() al pulsar una tecla. Con un array puedes guardar tantos elementos como quieras.

11 · Comprueba lo que sabes

Intenta responder con tus palabras antes de desplegar cada respuesta.

¿Qué es programar y qué hace un intérprete?

Programar es escribir instrucciones para que un ordenador realice una tarea. El intérprete lee ese texto y ejecuta las acciones que indica, línea a línea.

¿Qué diferencia hay entre setup() y draw()?

setup() se ejecuta una vez al empezar; draw() se repite en cada fotograma, unas 60 veces por segundo.

¿Qué pasos tiene una variable? Pon un ejemplo de dos tipos que no sean números.

Se declara (nombre), se le asigna un valor con = y se usa escribiendo su nombre. Ejemplos: un texto let nombre = "Ada"; para un marcador, y un booleano let pausa = false; para parar el juego.

¿Qué diferencia hay entre = y ===?

= asigna un valor a una variable; === compara dos valores y devuelve true o false.

¿Cuáles son las tres partes posibles de un condicional?

if (si se cumple), else if (si no, comprueba otra) y else (si no se cumple ninguna).

¿En qué se diferencian for y while?

for se usa cuando sabes cuántas vueltas habrá: lleva inicio, condición y paso en la misma línea. while se repite mientras se cumpla una condición, y eres tú quien debe hacer que deje de cumplirse.

¿Qué partes tiene una función y para qué sirve return?

Nombre, paréntesis con los parámetros que recibe y un bloque entre llaves con las instrucciones. return devuelve un resultado al punto desde el que se llamó a la función.
