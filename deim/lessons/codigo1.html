Fundamentos de programación en p5.js

Conceptos fundamentales para aprender a programar de forma visual y creativa.

01 · ¿Qué es la programación?

Programar es crear un conjunto de instrucciones que le dicen a un ordenador cómo realizar una tarea.

Esas instrucciones se escriben en un lenguaje que el ordenador puede entender. Unos traductores, los intérpretes, leen el texto y ejecutan las acciones que marca.

Aprender a programar es como aprender inglés, música o braille: damos sentido a unos signos para crear un sistema que funciona.

  • El código se ejecuta de arriba abajo, como leemos en la mayoría de lenguas occidentales. El orden importa.
  • Cada lenguaje tiene sus propias reglas de escritura (sintaxis).
  • Usaremos JavaScript con p5.js, una librería pensada para crear de forma visual.

02 · Variables

Una variable es un contenedor que guarda información que puede cambiar mientras el programa se ejecuta.

Piensa en tus variables como la paleta de elementos con la que después vas a jugar: los colores con los que pintarás o los objetos de un inventario.

En JavaScript se crean con let seguido del nombre. Para usarlas basta con escribir su nombre donde iría el valor.

let x = 50;          // guardamos un número en la variable x

function draw() {
  circle(x, 200, 50); // en vez de un número escribimos x
  x = x + 1;          // cambiamos su valor: el círculo se mueve
}

03 · Condicionales

Los condicionales permiten tomar decisiones: si se cumple una condición, se ejecuta un bloque de código.

let x = 0;

function draw() {
  x = x + 1;

  if (x > 200) {
    fill(255, 0, 0);  // a partir de 200: rojo
  } else {
    fill(0, 0, 255);  // antes: azul
  }

  circle(x, 200, 50);
}

if · else if · else

if (x < 100) {
  // primera condición
} else if (x < 200) {
  // si la primera no se cumple, se prueba esta
} else {
  // si no se cumple ninguna
}

05 · Bucles

Un bucle repite un fragmento de código mientras se cumple una condición, sin tener que escribirlo muchas veces.

Ojo: draw() ya es un bucle: p5.js lo ejecuta una vez por fotograma. Unity y cualquier motor que dibuje en tiempo real funcionan igual.

function draw() {
  background(220);

  // empieza en 0; sigue mientras x sea menor que el ancho; suma 20 en cada vuelta
  for (let x = 0; x < width; x = x + 20) {
    line(x, 0, x, height);
  }
}

06 · Funciones

Una función agrupa instrucciones con un nombre para poder invocarlas en cualquier momento.

Si las variables son los ingredientes, las funciones son las recetas. Los paréntesis pueden ir vacíos o recibir los datos (parámetros) que la función necesita para trabajar.

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(220);
  dibujarPelota(100, 200, 30);   // invocamos la función tres veces
  dibujarPelota(200, 200, 50);   // con datos distintos
  dibujarPelota(300, 200, 80);
}

// Declaramos nuestra propia función: recibe posición y tamaño
function dibujarPelota(px, py, tam) {
  fill(100, 150, 255);
  noStroke();
  circle(px, py, tam);
}

Importante: igual que con las variables, no puede haber dos funciones con el mismo nombre.

07 · Ejercicio: un sketch con ChatGPT

Vamos a crear un sketch con ChatGPT y a pedirle que nos explique cada proceso.

Objetivos

  • Diseñar un sketch en p5.js con los conceptos aprendidos: variables, condicionales, operadores, bucles y funciones.
  • Usar ChatGPT como herramienta para mejorar el código en varias iteraciones.
  • Entender el código resultante y poder explicarlo con tus palabras.

Requisitos mínimos

  • Al menos 3 versiones del código (3 mejoras sobre el original).
  • Al menos una variable propia, un condicional, un operador lógico (&&, || o !), un bucle y una función creada por ti.

Ejemplo de mensaje

cada proceso. Una frase y sin emojis.
