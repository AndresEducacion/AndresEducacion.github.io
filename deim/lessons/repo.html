Repositorio de códigos de Unity

Scripts de C# listos para usar y modificar. Despliega cada uno para ver el código completo, copiarlo o descargarlo.

Cómo usarlos

  1. En la ventana Project: botón derecho → Create → MonoBehaviour Script (en versiones anteriores, C# Script).
  2. Ponle exactamente el mismo nombre que la clase del código (por ejemplo, Jump2D). Si no coinciden, Unity no lo podrá añadir.
  3. Pega el código, guarda y arrastra el script al GameObject en el Inspector.
  4. Rellena las variables públicas en el Inspector y dale al Play.

Primeros pasos

Hello WorldO la importancia de Debug.Log.

Debug.Log imprime un valor en la consola. Sirve para saber qué está pasando: es muy útil para localizar errores y comprobar cómo funcionan de verdad tus procesos. Te sorprenderá cuántas veces las cosas no funcionan como piensas. Cuando pase: calma, paciencia, debuggea y lee con atención.
