Fundamentos de programación en C#

Los conceptos de la lección anterior escritos en C#, el lenguaje que usa Unity. Cambia la forma de escribir, no la lógica.

01 · ¿Qué es la programación?

Programar es crear un conjunto de instrucciones que le dicen a un ordenador cómo realizar una tarea.

La programación está totalmente mediada por el lenguaje. Aprender a programar es como aprender cualquier otro sistema de signos: inglés, música o braille. Damos sentido a los signos para crear un sistema que funciona.

Las instrucciones se escriben en un lenguaje que el ordenador puede entender, y unos traductores (compiladores o intérpretes) leen el texto y ejecutan las acciones que marca.

02 · Variables

Una variable es un contenedor que guarda información que puede cambiar mientras el programa se ejecuta.

A la hora de diseñar variables piensa en una paleta de elementos con la que luego vas a jugar, como en los juegos de construcción: las variables serían las piezas con las que después vas a construir.

Elementos de una variable

  1. Se declara: se le pone nombre. En C# además se indica el tipo de dato.
  2. Con el símbolo = se le asigna un valor inicial, que después puede cambiar.
let lifes = 3;      // JavaScript: no se indica el tipo
int damage = 120;   // C#: primero el tipo (int), luego el nombre

Unity: la sintaxis con corchetes (string[] frutas = ["melón", "pera"];) es de C# 12 y Unity todavía no la admite. Usa llaves { }.

Trucos y consejos

  1. Las variables más generales se suelen declarar al principio.
  2. Las variables que solo usa una acción se declaran junto a la función que se encarga de ella.
  3. Los nombres son cruciales para organizar el código: que digan lo más claro posible qué guardan, sin tildes ni espacios. En C# se escriben en camelCase: vidaMaxima, puertaAbierta.

03 · Operadores

Los operadores permiten hacer operaciones con números y con texto. Muchos son comunes a todos los lenguajes.

Aritméticos

int suma = a + b;
int resta = a - b;
int multiplicacion = a * b;
int division = a / b;       // entre enteros, se pierden los decimales: 7 / 2 = 3
int resto = a % b;          // el resto de la división: 7 % 2 = 1
float potencia = Mathf.Pow(a, 2);  // C# no tiene operador de potencia: se usa Mathf.Pow

De comparación

// con a = 10 y b = 5
bool esMayor = a > b;       // true
bool esMenor = a < b;       // false
bool esIgual = a == b;      // false  (== compara; = asigna)
bool esDistinto = a != b;   // true
bool mayorOIgual = a >= b;  // true
bool menorOIgual = a <= b;  // false

Lógicos

A menudo una condición necesita comprobar varias cosas a la vez. Para eso se usan los operadores lógicos.

04 · Estructuras de control

  1. if: comprueba una condición y, si se cumple, ejecuta el código entre llaves.
  2. else if: va después de un if. Si la condición anterior no se cumple, comprueba otra.
  3. else: va al final. Se ejecuta si no se ha cumplido ninguna de las condiciones anteriores.
if (impact > defense) {
    alive = false;                        // me he muerto
}
else if (impact < defense) {
    lives = lives - (defense - impact);   // me quita la diferencia
}
else {
    frozenState = true;                   // el único caso que queda: impacto igual a defensa
}

05 · Bucles

Los bucles son fragmentos de código que se repiten de forma cíclica mientras se cumple una condición.

while

Mientras se cumpla la condición, ejecuta la tarea. Un if dice «si pasa algo»; un while, «mientras pase algo».

int num = 0;
while (num < 10) {
    Debug.Log(num);   // imprime el número en la consola
    num++;            // le suma uno
}
// Se repite 10 veces (de 0 a 9). Cuando num llega a 10, la condición deja de cumplirse y el bucle termina.

for

Es el mismo bucle escrito de forma abreviada. Entre paréntesis lleva tres partes separadas por punto y coma:

  1. El valor inicial: normalmente la declaración de una variable.
  2. La condición que debe cumplirse para seguir dando vueltas, como en el while.
  3. La acción de cada vuelta: normalmente sumar uno a la variable (o restar, para contar hacia atrás).
for (int num = 0; num < 10; num++) {
    Debug.Log(num);
}
// Hace exactamente lo mismo que el while anterior. Se usa sobre todo en acciones secuenciales,
// como recorrer un array: for (int i = 0; i < frutas.Length; i++) { ... }

06 · Funciones

Una función es un conjunto de instrucciones que se agrupan para poder invocarlas en cualquier momento.

Música

Las variables serían las notas y las funciones la armonía. De hecho, se habla de «funciones armónicas».

Cine

Las variables serían los personajes y las funciones las escenas en las que actúan.

Cocina

La metáfora más usada: las variables son los ingredientes y las funciones, las recetas.

Cómo se declara una función

Se escribe el tipo de lo que devuelve (void si no devuelve nada), el nombre y unos paréntesis. Los paréntesis pueden ir vacíos o recibir los datos (parámetros) que la función necesita; esos parámetros se declaran ahí mismo.

void SaludoPersonalizado(string saludo) {
    Debug.Log(saludo);
}

SaludoPersonalizado("Heyyy");   // la invocamos: imprime "Heyyy"

// Al crear la función indico qué dato recibirá al invocarla: un saludo (string).
// Su acción es imprimir ese saludo.

Importante: igual que con las variables, no puede haber dos funciones con el mismo nombre (salvo que reciban parámetros distintos).

Nuestras propias herramientas

Las funciones nos permiten crear nuestras propias herramientas: son una oportunidad para construir cualquier proceso que se nos ocurra. Son más exigentes que un programa con interfaz visual, pero nos dan mucha más libertad.

Piensa en ellas como las máquinas de un proceso industrial:

  • Una máquina que corta regaliz: «cada tantos centímetros, corta».
  • Un termostato: «cuando la temperatura llegue a tantos grados, apágate».
  • Un brazo robot: guarda posiciones y las repite cuando se le ordena.
