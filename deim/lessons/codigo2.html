Fundamentos de programación en C#

Los conceptos de la lección anterior escritos en C#, el lenguaje que usa Unity. Cambia la forma de escribir, no la lógica.

01 · ¿Qué es la programación?

Programar es crear un conjunto de instrucciones que le dicen a un ordenador cómo realizar una tarea.

La programación está totalmente mediada por el lenguaje. Aprender a programar es como aprender cualquier otro sistema de signos: inglés, música o braille. Damos sentido a los signos para crear un sistema que funciona.

Las instrucciones se escriben en un lenguaje que el ordenador puede entender, y unos traductores (compiladores o intérpretes) leen el texto y ejecutan las acciones que marca.

02 · Variables

Una variable es un contenedor que guarda información que puede cambiar mientras el programa se ejecuta.

A la hora de diseñar variables piensa en una paleta de elementos con la que luego vas a jugar, como en los juegos de construcción: las variables serían las piezas con las que después vas a construir.

Elementos de una variable

  1. Se declara: se le pone nombre. En C# además se indica el tipo de dato.
  2. Con el símbolo = se le asigna un valor inicial, que después puede cambiar.
let lifes = 3;      // JavaScript: no se indica el tipo
int damage = 120;   // C#: primero el tipo (int), luego el nombre

03 · Operadores

Los operadores permiten hacer operaciones con números y con texto. Muchos son comunes a todos los lenguajes.

Aritméticos

int suma = a + b;
int resta = a - b;
int multiplicacion = a * b;
int division = a / b;       // entre enteros, se pierden los decimales: 7 / 2 = 3
int resto = a % b;          // el resto de la división: 7 % 2 = 1
float potencia = Mathf.Pow(a, 2);  // C# no tiene operador de potencia: se usa Mathf.Pow

Con texto

El + también une textos (concatena). Es lo que más usarás con Debug.Log para ver qué valen tus variables.

string nombre = "Ada";
int vidas = 3;
Debug.Log("Jugadora: " + nombre + " · vidas: " + vidas);
Jugadora: Ada · vidas: 3

De comparación

// con a = 10 y b = 5
bool esMayor = a > b;       // true
bool esMenor = a < b;       // false
bool esIgual = a == b;      // false  (== compara; = asigna)
bool esDistinto = a != b;   // true
bool mayorOIgual = a >= b;  // true
bool menorOIgual = a <= b;  // false

Lógicos

A menudo una condición necesita comprobar varias cosas a la vez. Para eso se usan los operadores lógicos.

04 · Estructuras de control

  1. if: comprueba una condición y, si se cumple, ejecuta el código entre llaves.
  2. else if: va después de un if. Si la condición anterior no se cumple, comprueba otra.
  3. else: va al final. Se ejecuta si no se ha cumplido ninguna de las condiciones anteriores.
int impact = 30;
int defense = 50;
int lives = 100;
bool alive = true;
bool frozenState = false;

if (impact > defense) {
    alive = false;                        // me he muerto
}
else if (impact < defense) {
    lives = lives - (defense - impact);   // me quita la diferencia
}
else {
    frozenState = true;                   // el único caso que queda: impacto igual a defensa
}

Debug.Log("Vidas: " + lives + " · vivo: " + alive + " · congelado: " + frozenState);
Vidas: 80 · vivo: True · congelado: False

Prueba mentalmente: ¿qué saldría con impact = 60? ¿Y con impact = 50?

05 · Bucles

Los bucles son fragmentos de código que se repiten de forma cíclica mientras se cumple una condición.

while

Mientras se cumpla la condición, ejecuta la tarea. Un if dice «si pasa algo»; un while, «mientras pase algo».

int num = 0;
while (num < 10) {
    Debug.Log(num);   // imprime el número en la consola
    num++;            // le suma uno
}
// Se repite 10 veces (de 0 a 9). Cuando num llega a 10, la condición deja de cumplirse y el bucle termina.
0
1
2
…
9

for

Es el mismo bucle escrito de forma abreviada. Entre paréntesis lleva tres partes separadas por punto y coma:

  1. El valor inicial: normalmente la declaración de una variable.
  2. La condición que debe cumplirse para seguir dando vueltas, como en el while.
  3. La acción de cada vuelta: normalmente sumar uno a la variable (o restar, para contar hacia atrás).
for (int num = 0; num < 10; num++) {
    Debug.Log(num);
}
// Hace exactamente lo mismo que el while anterior, con el contador en una sola línea.

Recorrer un array

El uso más habitual de for es recorrer una lista con un índice. Si no necesitas el índice, foreach lo hace más corto: «para cada elemento de la lista».

string[] inventario = { "espada", "escudo", "poción" };

for (int i = 0; i < inventario.Length; i++) {
    Debug.Log(i + ": " + inventario[i]);       // con el número de posición
}

foreach (string objeto in inventario) {
    Debug.Log("Tienes: " + objeto);           // sin índice
}
0: espada
1: escudo
2: poción
Tienes: espada
Tienes: escudo
Tienes: poción

for

Cuando sabes cuántas vueltas habrá o necesitas el número de vuelta.

while

Cuando es una condición la que decide: «mientras el enemigo esté vivo».

foreach

Para recorrer todos los elementos de una lista, uno a uno.

Cuidado con los bucles infinitos: si la condición nunca deja de cumplirse, Unity se queda colgado y tendrás que cerrarlo. Comprueba siempre que algo dentro del bucle acerca el final.

06 · Funciones

Una función es un conjunto de instrucciones que se agrupan para poder invocarlas en cualquier momento.

Música

Las variables serían las notas y las funciones la armonía. De hecho, se habla de «funciones armónicas».

Cine

Las variables serían los personajes y las funciones las escenas en las que actúan.

Cocina

La metáfora más usada: las variables son los ingredientes y las funciones, las recetas.

Cómo se declara una función

Se escribe el tipo de lo que devuelve (void si no devuelve nada), el nombre y unos paréntesis. Los paréntesis pueden ir vacíos o recibir los datos (parámetros) que la función necesita; esos parámetros se declaran ahí mismo.

void SaludoPersonalizado(string saludo) {
    Debug.Log(saludo);
}

SaludoPersonalizado("Heyyy");   // la invocamos: imprime "Heyyy"

// Al crear la función indico qué dato recibirá al invocarla: un saludo (string).
// Su acción es imprimir ese saludo.
Heyyy

Importante: igual que con las variables, no puede haber dos funciones con el mismo nombre (salvo que reciban parámetros distintos).

Funciones que devuelven un resultado

Si en lugar de void pones un tipo, la función debe devolver un valor de ese tipo con return. Ese valor vuelve al punto desde el que se llamó.

int CalcularDanio(int ataque, int defensa) {
    int danio = ataque - defensa;   // variable local: solo existe dentro de esta función
    if (danio < 0) {
        danio = 0;                  // el daño nunca puede ser negativo
    }
    return danio;                   // devuelve el resultado
}

int golpe = CalcularDanio(120, 40);
Debug.Log("Daño: " + golpe);
Debug.Log("Daño: " + CalcularDanio(20, 50));
Daño: 80
Daño: 0

Variables globales y locales

Una variable declarada fuera de las funciones (en la clase) la pueden usar todas. Una declarada dentro de una función solo existe ahí y desaparece al terminar.

public class Jugador : MonoBehaviour
{
    int vidas = 3;               // global (de la clase): la ven todas las funciones

    void RecibirGolpe()
    {
        int danio = 1;           // local: solo existe dentro de RecibirGolpe
        vidas -= danio;
        Debug.Log("Te quedan " + vidas + " vidas");
    }
}

Nuestras propias herramientas

Las funciones nos permiten crear nuestras propias herramientas: son una oportunidad para construir cualquier proceso que se nos ocurra. Son más exigentes que un programa con interfaz visual, pero nos dan mucha más libertad.

Piensa en ellas como las máquinas de un proceso industrial:

  • Una máquina que corta regaliz: «cada tantos centímetros, corta».
  • Un termostato: «cuando la temperatura llegue a tantos grados, apágate».
  • Un brazo robot: guarda posiciones y las repite cuando se le ordena.

07 · Trucos y consejos

Variables

Declara las globales al principio, fuera de las funciones, y no abuses de ellas. Las locales van dentro de la función que las usa. Nombres claros: cubeVelocity, maxCubeVelocity.

Condicionales

Ordena de la condición más concreta a la más general. Agrupa condiciones relacionadas con operadores lógicos.

Operadores

Usa la asignación abreviada: x += 2 en vez de x = x + 2, y x++ en vez de x = x + 1.

Bucles

for si sabes cuántas vueltas habrá; while si manda una condición. Evita los bucles infinitos y pon dentro solo lo imprescindible.

Funciones

Una función, una tarea. Si pasa de 50–70 líneas, divídela. Mejor pasar datos por parámetros y devolverlos con return que modificar variables globales.

// Con booleanos no hace falta comparar con true
if (isReady == true) { … }    // funciona, pero sobra
if (isReady) { … }            // mejor

// Agrupa condiciones relacionadas
if (age >= 18 && hasID) {
    Debug.Log("Puedes pasar");
}

09 · Comprueba lo que sabes

Intenta responder con tus palabras antes de desplegar cada respuesta.

¿Qué diferencia hay entre declarar una variable en JavaScript y en C#?

En C# hay que indicar el tipo antes del nombre (int vidas = 3;); en JavaScript basta con let.

¿Por qué los decimales llevan una f en C#?

Porque sin ella C# entiende que el número es un double. La f lo marca como float, el tipo decimal que usa Unity.

¿Cuánto vale 7 / 2 entre enteros? ¿Y 7 % 2?

7 / 2 vale 3, porque entre enteros se pierden los decimales. 7 % 2 vale 1: es el resto.

Escribe un condicional con sus tres partes.

if (vida > 50) { … } else if (vida > 0) { … } else { … }: si se cumple la primera, si no la segunda, y si no ninguna.

¿Cuándo usarías for, while o foreach?

for si sabes cuántas vueltas habrá, while si manda una condición y foreach para recorrer todos los elementos de una lista.

¿Qué significa void? ¿Qué pasa si pones int en su lugar?

void indica que la función no devuelve nada. Con int, la función está obligada a devolver un número entero con return.

¿Qué diferencia hay entre una variable global y una local?

La global se declara en la clase y la ven todas las funciones. La local se declara dentro de una función y solo existe mientras esa función se ejecuta.
